Customer Behaviour Analysis
Project Overview
This project focuses on analyzing customer behaviour using data analysis techniques. The goal is to understand how customers interact with products, their purchase patterns, and what factors influence their buying decisions.

Objectives
To analyze customer purchase patterns
To identify high-value customers
To understand product preferences
To study relationship between customer demographics and spending behavior
To help businesses make data-driven decisions

Dataset Information
The dataset contains customer-related data such as:
Customer ID
Age
Gender
Purchase History
Product Categories
Spending Amount
Subscription Status 

Tools & Technologies Used
Python 
Power BI
Jupyter Notebook

Key Analysis Performed
Customer segmentation (New, Returning, Loyal)
Revenue analysis by age group
Top-selling products identification
Spending behavior comparison
Discount usage impact on purchases

Insights
Loyal customers contribute most to revenue
Certain age groups spend more than others
Some products are consistently top-rated and highly purchased
Discount users show different buying patterns compared to non-discount users

Conclusion
This project helps in understanding customer behaviour deeply, which can help businesses improve marketing strategies, increase sales, and enhance customer satisfaction.
